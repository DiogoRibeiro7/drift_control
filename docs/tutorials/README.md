# Tutorials

Scenario-driven tutorials for common drift-control workflows.

- `univariate-batch.ipynb`: batch univariate drift checks with KS/PSI, JSON output, and report export.
- `streaming-multivariate.ipynb`: streaming monitor setup with adaptive thresholds, sliding baseline, and alert sinks.
- `slice-drift.ipynb`: cohort-level drift detection to catch segment regressions hidden in global aggregates.
- `embedding-drift.ipynb`: multivariate drift checks on precomputed embedding vectors using MMD and Energy detectors.
- `image-embedding-drift.ipynb`: image embedding drift checks with custom embedder and optional torchvision default.
